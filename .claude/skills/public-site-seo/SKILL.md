# Public site + SEO

## Pages (all under `/{locale}`)

| Route | Component | Notes |
|---|---|---|
| `/` | `Site\Home` | Banners, featured products, category tiles, brands, services teaser, CTA to quote |
| `/catalog/{category:slug}` | `Site\Catalog\Category` | Subcategories, filters (brand, price, filterable attributes), sort, pagination with `#[Url]` |
| `/product/{product:slug}` | `Site\Catalog\Product` | Gallery, specs table, documents, accessories/consumables, Cart and/or Request quote buttons |
| `/brands/{brand:slug}` | `Site\Catalog\Brand` | |
| `/services`, `/software` | product type listings | Services always use the quote form |
| `/search` | `Site\Search` | Matches SKU, model and name in the current locale |
| `/news`, `/news/{slug}` | | |
| `/page/{slug}` | | About, delivery, warranty, contacts |
| `/cart`, `/checkout` | see `cart-checkout` | |

## Components

- `Site\QuoteRequestForm` is a modal or inline form. It accepts a product ID or a cart of products and creates a lead through the `CreateQuoteRequest` action (see `crm-leads-quotes`). Protect it with a rate limit and a honeypot.
- `Site\CallbackForm` covers "call me back" and service requests.
- The language switcher keeps the same page and swaps the locale.

## SEO checklist (each public page)

- `<title>` and `meta description` come from the model's `seo` json for the locale, falling back to a template such as "{name} — buy in Tashkent | Poson".
- Canonical URL. `hreflang` alternates for uz, ru and en, plus `x-default` set to uz.
- Open Graph and Twitter tags with the product image.
- JSON-LD:
  - Product page: `Product` with brand, sku, image and `offers` (`priceCurrency: UZS`, availability from stock_status). Omit `offers.price` when the price is on request.
  - All pages: `BreadcrumbList`.
  - Home: `Organization` and `LocalBusiness`.
- `sitemap.xml` is generated by an artisan command and scheduled daily. It covers all locales for categories, products, brands, pages and news.
- `robots.txt` disallows `/admin`, `/cart`, `/checkout` and filter query URLs.
- Images: `loading="lazy"`, width and height attributes, alt text from the translatable `alt`.
- Filtered listing URLs get `noindex,follow` when more than one filter is active.

## Performance

- Cache the category tree and menus (`Cache::remember`, flushed in model observers).
- Paginate at 24 per page and eager-load relations.
